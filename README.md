# 高性价比打工指南

> 每条建议都算清楚：**花多少工时，换多少收益，值不值你的时薪。**

**在线阅读**：https://louiseai.site

一本写给一线城市打工人（月薪 1-3 万）的决策手册，28 章 93 条，覆盖打工生命周期全程：
**进场 → 在职 → 风险 → 转折**，外加一份反面清单。

灵感来自 [howtolivebetter.net](https://howtolivebetter.net) 的《高性价比人生指南》——感谢原作示范了「把建议写成可执行的账」这件事该怎么做。

## 和一般「职场建议」的区别

**1. 阈值线，不是口号。**
每条建议都有一个可代入的数字判断：

```
值得投入 ⟺ 预期收益 / 占用工时 ≥ 你的时薪
```

「要不要接私活」「要不要考在职研究生」这类问题，对时薪 30 元和时薪 150 元的人，答案完全相反。本书不给统一答案，给统一的算法。

**2. 三种收益分开记账，不合成总分。**
现金流（马上到账）、工龄复利（社保/年假/年金）、议价权（跳槽筹码/行业信用）是三种货币，互相不能换算。省下的钱和避免的风险，永远不排在同一把尺子上。

**3. 法条必标出处与时效。**
每条法律相关建议注明文件名、文号、生效日期，并区分全国统一规定与地方口径。例如：加班费计算基数依据人社部发〔2025〕2 号；违法解除赔偿依据《劳动合同法》第 87 条。**本书不构成法律意见**，个案请咨询执业律师。

**4. 不确定就写不确定。**
查不到全国统一规定的（如病假工资地方口径差异），明确标注「各地有差异」，不写成确定结论。

## 特色功能

- **真实时薪测算器**：输入月薪和实际工时（含通勤、加班），算出你真正的时薪——多数人算完会沉默
- **每日一问**：每天一道「待算的账」，按日期轮换，把阈值思维练成习惯
- **全书检索**：按章节、关键词、收益类型筛选 93 条建议
- **免费下载**：PDF / Word / Markdown 三格式，公众号验证码登录后获取，30 天有效
- **数据即代码**：全书内容是结构化数据（`src/data/chapters/`），网站和下载文件从同一份数据生成

## 技术栈

Vite + React + TypeScript，零后端框架；登录与昵称服务为 Cloudflare Pages Functions + KV。

```bash
npm install
npm run dev        # 本地开发
npm run validate   # 内容校验（强制出处、阈值线、证据理由）
npm run build      # 构建到 dist/
```

## 项目结构

```
src/data/chapters/   # 全书内容（28 章，数据即代码）
src/lib/calc.ts      # 真实时薪计算逻辑
functions/api/       # Cloudflare Pages Functions（登录、昵称）
scripts/             # 导出、校验、演示脚本
docs/                # 全书 Markdown 导出、方案文档
```

## 内容纪律

- 平均工资类数据一律标注统计口径（税前/税后、是否含加班、覆盖人群），优先使用人社部**分位值**数据而非平均数
- 引用的研究不冒充官方数据（如教育回报率来自学术研究，非统计局）
- 每条建议的证据分级 A/B/C，法律条目单独标记
