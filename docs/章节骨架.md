## 写作纪律（每章都要过）

1. **出处必填**：每条 `sources` 含文件名 + 文号 + 生效日期 + 链接，`npm run validate` 强制
2. **三步 checklist**：恰好 3 条、动词开头（validate 强校验）
3. **阈值线**：`hourly`（真需要时间投入换收益的）/ `years`（权利窗口类）/ `none`（法条要件、金额规则类，below 写清无条件动作）
4. **派生即写推导**：`derivation` 字段写清数字怎么来的，写不出来就别设值
5. **法律条目标地区差异与争议点**，`legal: true` 触发免责提示
6. **不确定就写不确定**：查不到全国统一规定的直接标注「各地口径有差异」
7. **review 原文引用优先**：改法条前先搜原文，「看起来像漏字」先做语法分析
